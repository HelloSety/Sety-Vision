# Second Brain via Obsidian — princípios adotados

Seven enviou um mega prompt definindo uma filosofia completa de "Second Brain" em Obsidian (links, tags, metadata, backlinks, nenhuma nota órfã, dashboards via Dataview).

**Decisão:** adotar como instrução permanente de prática — não reestruturar as pastas do [[MEMORY]] hoje. A estrutura `MEMORY/` (CLIENTES, PROJETOS, CAMPANHAS, PLAYBOOKS, DECISOES, PROMPTS, TEMPLATES) continua sendo a única fonte da verdade.

**Confirmado com Seven:**
- Ele abre este repo pelo app Obsidian de fato (não é só markdown solto) — Dataview/Canvas são viáveis quando fizer sentido criar um dashboard.
- Regra registrada em `CLAUDE.md` → seção "Princípios do Second Brain (Obsidian)".

Reformular tudo agora seria retrabalho sem necessidade concreta — melhor aplicar os princípios (frontmatter, links, nenhuma nota órfã) nas notas que já são criadas no fluxo normal.

**Próximos passos:** se Seven pedir um dashboard consolidado (clientes ativos, projetos, pipeline), aí sim vale criar uma nota com Dataview query dentro do vault.
