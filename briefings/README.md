# briefings/ — antes de virar cliente

Aqui ficam os briefings de empresas em fase de prospecção ou proposta,
antes de fecharem como cliente.

Um arquivo por empresa: `briefings/<empresa>.md`.

Quando a empresa fecha, o conteúdo migra pra `clientes/<Nome>/` via
`/novo-projeto` e este arquivo pode ser arquivado ou apagado.
