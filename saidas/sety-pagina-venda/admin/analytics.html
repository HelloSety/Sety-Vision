04 Ativação (o que falta)

  • 1. No painel da Vercel: Project → Analytics → Enable Web Analytics. Grátis. A partir daí os números acima começam a preencher.
  • 2. (opcional) Speed Insights → Enable — Core Web Vitals de campo real dos visitantes.
  • 3. (opcional) Google Analytics 4: criar propriedade, colar o G-XXXXXXXX em js/config.js → TRACKING_CONFIG.googleAnalyticsId. Dá relatório por mês / canal / UTM.
  • 4. Conferir que está disparando: abrir a home, DevTools → Network → filtrar _vercel/insights (deve aparecer view e event nos cliques).
  • 5. Search Console: verificar o domínio e enviar /sitemap.xml (SEO, separado do tráfego).

05 Como ler o tráfego

  • Volume → page_view. Subindo = alcance crescendo (orgânico + anúncio).
  • Qualidade → razão click_whatsapp / page_view. É a taxa de conversão da página. Meta inicial saudável: 3–8%.
  • De onde vem → UTM nos page_view + referrer no painel Vercel. Separe orgânico, direto, Meta Ads, Google Ads.
  • Onde trava → scroll_depth. Se cai muito entre 25% e 50%, o problema está na primeira metade (hero/problema).
  • O que convence → resultado_open e faq_open altos antes de um click_whatsapp = prova e FAQ estão fazendo o trabalho.
